# Glitch Strike: Operation Bug

A 3D first-person shooter. You fall into the Backrooms and its other levels and fight different monsters.

## Features

- First-person 3D shooting in the Backrooms and several other levels
- Different monsters to fight
- Multiple weapons that you buy in the in-game store
- Secrets hidden across the levels

## Controls

| Key | Action |
| --- | --- |
| WASD | Walk |
| Space | Jump |
| Shift + WASD | Run |
| Right mouse button | Shoot |
| Left mouse button | Zoom |
| R | Reload |
| B | Store |
| T | Teleport |

## Requirements

- Unity 2022.3.55f1 (see `ProjectSettings/ProjectVersion.txt`)
- Third-party package in `Assets/Mirror` (Mirror networking), already included in the repo

## Open the project

1. Install Unity 2022.3.55f1 via Unity Hub.
2. Clone this repo and add the folder in Unity Hub (Add > Add project from disk).
3. Open the project. Unity regenerates `Library/` on first launch, it can take a few minutes.

## Builds

Ready-made builds are in a separate repo: https://github.com/SDH4114/Glitch-Strike-Operation-Bug

## Project structure

